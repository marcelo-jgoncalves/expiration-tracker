## Achados point-fix (aplicáveis nesta sessão, antes da próxima rodada)

1. **Critério 3 (Licenciamento)**: adicionar `LICENSE` real + campo `license` em `package.json`. Point-fix genuíno, sem dependência externa.
2. **Critério 2 (Inventário)**: criar `docs/engineering/third-party-inventory.md` versionado com as colunas exigidas pelo critério, extraindo os fornecedores já citados em `privacy-lgpd.md:49` — não é escopo novo, é formalizar informação que já existe em prosa.

## Achados classificados como impedimento externo real ou escopo maior (não corrigíveis nesta sessão)

- **Critério 1**: decisão de papel jurídico (controlador/operador) exige parecer jurídico real — impedimento externo, já corretamente gated em `privacy-lgpd.md:53`.
- **Critério 4**: Termos de Uso/Aviso de Privacidade voltados ao usuário final são conteúdo de produto + revisão jurídica, não documentação técnica — escopo maior, pré-requisito de lançamento já registrado como tal.
- **Critério 5**: DPA real depende de contrato real com fornecedor — não há fornecedor sob DPA hoje (Bedrock/Textract ainda não contratados/habilitados para uso real).
- **Critério 6**: superfície comercial real (preço, cancelamento) não existe porque não há oferta comercial lançada — proporcional ao estágio pré-produção.
- **Critério 8**: estratégia formal de saída de fornecedor é esforço de projeto (probavelmente um documento próprio tipo ADR), não uma correção pontual de uma sessão.
