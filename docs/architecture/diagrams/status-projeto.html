Controle de Vencimentos · Fase 3 em andamento

Fundação aprovada, arquitetura AWS em rodada de consenso e nota

Requisitos (Fase 1) e capacity model (Fase 2) já passaram por debate Claude↔Codex e avaliação independente às cegas, com nota ≥9.0 de ambos. A Fase 3 já tem uma arquitetura AWS conceitual consolidada — Lambda, DynamoDB on-demand, S3, SQS, EventBridge, Cognito — construída por propostas independentes, crítica cruzada e tréplica, mas ainda não atingiu nota ≥9.0 de ambos: a primeira avaliação expôs um problema real no processo (a rubrica de nota exigia evidência de implementação, impossível antes da arquitetura ser aprovada) e foi corrigida com duas rubricas formais. Rodadas de fechamento de ADRs e reavaliação continuam.

Serviços AWS já propostos (não implementados). Lambda + API Gateway HTTP API + DynamoDB single-table + S3 (quarentena de 2 buckets) + Cognito + EventBridge + SQS por canal + Textract/Bedrock + CDK. Todas as decisões têm justificativa rastreada a requisitos e ao capacity model, com trade-offs e alternativas rejeitadas registrados — nada foi escolhido "porque é óbvio".
